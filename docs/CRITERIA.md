# 기준 문서 (계산·오류·검증)

근거: data/programs/RULES.md, 2024.csv, 2025.csv, 2026.csv, errors.csv. 아래 수치는 로컬 python으로 직접 계산해 확인했다.

## 1. 입력 형식
- 열 이름과 순서(고정): `연도,사업ID,사업명,분야,지역,참여자수,수료자수`
- 인코딩 UTF-8. 맨 앞 BOM(U+FEFF)이 있으면 제거한 뒤 첫 열 이름을 비교한다. 실제 샘플 4개 파일 모두 BOM이 있다.
- 빈 줄(공백만 있는 줄 포함)은 무시하며 제외 행으로 세지 않는다.
- 모든 셀은 앞뒤 공백을 trim한 뒤 처리한다. 줄바꿈은 CRLF/LF 모두 허용한다.
- 열 이름이 다르거나 열 수가 모자라면 파일 전체를 읽지 않고 "열 이름이 올바르지 않습니다" 안내를 표시한다. 열 순서가 달라도 열 이름으로 찾아 읽어도 되지만, 출력은 항상 위 순서다.
- 연도는 정수, 사업ID는 비어 있지 않은 문자열이어야 한다. 사업ID 또는 연도가 비면 중복 판단이 불가능하므로 "필수값 누락"이 아니라 아래 1순위 사유에 준해 제외한다(샘플에는 없음).
- 쉼표가 들어간 값은 큰따옴표 CSV 규칙을 따른다.
- 파일 선택으로 새 자료를 읽을 수 있어야 한다. 정상 파일과 오류 파일은 섞지 않고 한 번에 한 파일(또는 한 묶음)만 처리한다. 기본 샘플은 2024+2025+2026(18행)이다.

## 2. 행 검증 순서와 제외 사유
행은 위에서 아래 순서로 검사하고 첫 번째로 걸린 사유 하나만 기록한다(복수 사유가 있어도 우선순위가 높은 하나).

| 순위 | 검사 | 제외 사유 문구(고정 문자열) |
|---|---|---|
| 1 | 참여자수 또는 수료자수가 빈 값 | `숫자 누락` |
| 2 | 정수가 아님(소수점, 문자, 1e3 등. 정규식 `^-?\d+$` 불일치) | `정수 아님` |
| 3 | 0 미만 | `음수` |
| 4 | 수료자수 > 참여자수 | `수료자 초과` |
| 5 | 같은 (연도+사업ID)의 유효한 행이 이미 있음 | `중복` |

- 중복(5순위)은 1~4순위를 모두 통과한 행끼리만 비교한다. 무효 행은 "첫 행" 판단에서 제외한다. 예: 같은 연도+사업ID의 첫 행이 숫자 누락이고 둘째 행이 정상이면 둘째 행이 유효한 첫 행으로 남고 중복이 아니다.
- 중복의 기준 키는 연도+사업ID 두 값뿐이다. 사업명·수치가 달라도 키가 같으면 뒤의 유효 행은 `중복`이다.
- 제외 행은 원본 줄 번호(헤더 제외 데이터 행 기준 1부터)·원본 값·사유를 목록으로 보여 준다. 합계·차트·표·CSV에는 넣지 않는다.
- 이 단계는 필터와 무관하게 파일 전체에 대해 한 번 수행한다. 연도 필터는 검증을 통과한 유효 행에만 적용한다.

## 3. 0명 행(참여자 0, 수료자 0)
- 유효 행이다(수료자 ≤ 참여자, 0 이상 정수). 표·CSV에 남긴다.
- 개별 수료율 표시: `계산 불가`. 판정 표시: `계산 불가`. 사유 문구: `참여자 0명`.
- 주의 항목 수에는 세지 않는다(주의도 정상도 아님).
- 참여자·수료자 합계에는 0으로 포함되므로 합계 값은 변하지 않는다. 사업 수(고유 사업ID)에는 포함된다.

## 4. 계산식과 표시
- 개별 수료율 = 수료자 ÷ 참여자 × 100 (참여자 0이면 계산 불가).
- 전체 수료율 = 합산 수료자 ÷ 합산 참여자 × 100. 사업별·행별 비율의 단순 평균은 사용하지 않는다. 합산 참여자가 0이면 `계산 불가`.
- 연도별 수료율(꺾은선) = 그 연도 유효 행의 수료자 합 ÷ 참여자 합 × 100. 합산 참여자 0이면 해당 점은 `계산 불가`로 비우고 선을 잇지 않는다.
- 반올림은 표시 단계에서만 한다. 내부는 반올림하지 않은 값(가능하면 정수 분자·분모)으로 판정한다. 반올림은 반올림(half up).
  - 요약 카드의 전체 수료율: 정수 %, 예 `83%`.
  - 표(행별 수료율)·차트 값·연도별 꺾은선 라벨: 소수 1자리 %, 예 `75.0%`, `82.6%`.
  - 인원은 천 단위 쉼표, 예 `1,410명`.
- 부동소수 오차를 피하려고 판정은 `수료자 × 100 < 기준값 × 참여자` 정수 비교로 한다.

## 5. 판정
- 기본 주의 기준값 70(%). 규칙: 개별 수료율 < 기준값이면 `주의`, 이상이면 `정상`. 경계값은 미만이므로 정확히 기준값이면 `정상`.
- 기준값은 사용자가 바꿀 수 있고(0~100), 바꾸면 판정·주의 항목 수·표를 즉시 다시 계산한다. 합계·전체 수료율은 변하지 않는다.
- 판정은 행 단위다. 전체/연도 합산 수료율에는 판정을 붙이지 않는다.
- 규칙 변경 사례(기준 80%): errors.csv의 75%(20명 중 15명) 행은 `주의`, 정확히 80%인 행(2024 P02, 60명 중 48명)은 `주의 아님(정상)`.

## 6. 요약 6개
1. 참여자 합계: 필터된 유효 행의 참여자수 합.
2. 수료자 합계: 필터된 유효 행의 수료자수 합.
3. 전체 수료율: 2번 ÷ 1번 × 100, 정수 %. 1번이 0이면 `계산 불가`.
4. 사업 수: 필터된 유효 행의 고유 사업ID 개수.
5. 선택 연도 수: 필터된 유효 행에 실제로 존재하는 고유 연도 수(체크한 연도 중 유효 행이 없는 연도는 세지 않는다고 정의, 샘플은 모두 존재해 선택 수와 같다).
6. 주의 항목 수: 필터된 유효 행 중 판정이 `주의`인 행 수(`계산 불가` 제외).

## 7. 필터
- 연도 필터: 체크박스 다중 선택, 기본은 파일에 있는 모든 연도 선택. 모두 해제하면 "연도를 하나 이상 선택하세요" 안내를 표시하고 요약은 0 또는 `계산 불가`로 둔다.
- 요약 6개, 파이(분야별 참여자 합), 막대(사업별 참여자 합·수료자 합, 사업ID별 2개 막대), 꺾은선(연도별 합산 수료율), 상세 표, CSV 내보내기는 모두 같은 "필터된 유효 행" 배열에서 계산한다. 제외 행은 어느 곳에도 들어가지 않는다.
- 막대의 사업별 값은 필터된 연도들을 합산한다. 꺾은선은 선택한 연도만 표시한다.
- 파이의 분야 색과 막대의 참여/수료 색은 고정 매핑(필터로 항목이 없어져도 나머지 색 유지). 모든 차트에 제목, 단위(명 또는 %), 범례, 값 라벨, 읽기 안내 문장을 둔다.

## 8. CSV 출력
- 열 이름과 순서는 입력과 동일: `연도,사업ID,사업명,분야,지역,참여자수,수료자수`. 수료율·판정 열은 넣지 않는다.
- 필터된 유효 행만, 입력 순서대로. 제외 행·0명 아닌 계산 불가 열은 없다. 0명 행은 `0,0`으로 포함한다.
- UTF-8 BOM을 붙이고 줄바꿈은 CRLF 또는 LF 하나로 통일한다. 쉼표·따옴표·줄바꿈이 있는 값은 큰따옴표로 감싸고 내부 따옴표는 두 번 쓴다.
- 내보낸 CSV를 다시 읽으면 제외 0건, 같은 행 수·합계가 나와야 한다(왕복 검증).
